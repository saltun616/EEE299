# FPGA-Based Snake Game

This project implements the classic Snake game in Verilog on a Digilent Basys3 FPGA. The game is displayed on a VGA monitor. The snake is steered with the onboard buttons and the onboard seven-segment display shows the player's score. The snake is drawn in pink and the "food" items are purple hearts. Following the original rules of the game, the snake grows longer each time it reaches the food and the number of food items eaten is shown on the seven-segment display. The game ends when the snake hits a wall or itself. When the game ends the screen turns red and displays "TRY AGAIN".

The snake starts at a length of three cells in the middle of the screen and can grow up to 64 cells. The snake's body coordinates are stored in flattened registers. On each game tick the body shifts forward, a new head position is computed from the current direction. The design checks for wall collisions, self collisions and whether the food was eaten. When food is eaten, the length and score increase and a new food position is generated.

The design is made up of six modules. `top.v` integrates all the modules and drives the VGA color output based on the game state. `vga_sync.v` generates the 25 MHz pixel timing, hsync and vsync pulses, and pixel coordinate counters from the 100 MHz system clock. `debounce.v` waits to confirm that a pushbutton input is valid and not noise. `lfsr.v` is a linear feedback shift register used to randomize food placement. `snake_game.v` stores the snake body's placement and handles its movement, growth, collision detection and scoring. `seven_seg.v` is a multiplexed BCD-to-seven-segment driver that displays the score.
