# AXI Stream FIFO Demonstration Using UART

This project demonstrates the AXI Stream FIFO protocol on a Digilent Basys3 FPGA using UART communication, written in VHDL. The system allows bidirectional data transfer between a computer and the Basys3 through a FIFO buffer. Data can be entered in two ways: as hexadecimal values using the onboard switches, or directly from the computer keyboard through a 115200-baud UART connection using TeraTerm. Every byte received is stored in the FIFO. When the center button on the board is pressed, the stored bytes are sent back to the TeraTerm terminal one by one, in the order they were entered. The hardware used is the Basys3 board (switches, center button, LEDs and seven-segment display), a computer running TeraTerm and the computer keyboard.

The seven-segment display and LEDs report the state of the FIFO. The two digits on the left show the hexadecimal value of the character the read pointer is currently on, which is the first byte that was entered, and the two digits on the right show how many bytes are currently stored. For example, while typing the word "EYLUL", the display shows 45 (the hexadecimal code for "E") on the left and 03 on the right once "EYL" has been stored. Pressing the center button then sends all characters to TeraTerm, where the full word appears.

The design consists of five VHDL modules. The top-level module, `basys3_axis_fifo_uart_demo.vhd`, stores bytes received from the switches or the PC in a FIFO queue, sends them back over serial when the button is pressed and drives the status display. The module `debounce_onepulse.vhd` filters mechanical switch noise from a button input and produces a single clean pulse. The module `uart_rx.vhd` receives serial data one bit at a time, assembles it into a byte, and raises a valid flag, while `uart_tx.vhd` takes an 8-bit byte and transmits it one bit at a time over the serial line. Finally, `axis_fifo.vhd` implements a synchronous FIFO buffer, 8 bits wide and 16 entries deep by default, that uses the AXI Stream valid/ready handshake on both its input and output interfaces and provides full, empty and count status flags.
