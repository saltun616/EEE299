# FPGA-Based Tetris 

This project implements the classic game Tetris in Verilog on a Digilent Basys3 FPGA. The game is displayed on a VGA monitor and played with a 4×4 matrix keypad. The onboard LEDs show how many lines have been cleared. At startup the screen reveals a 10×20 playing area surrounded by a white border with pieces drawn in different colors.

Gameplay is controlled by a finite state machine inside `tetris_game.v`, which governs every falling piece. First, a new piece is generated and placed at the top of the board. During the falling state, keypad inputs can move the piece or rotate it: pressing "2" rotates the shape, "4" moves it left, "6" moves it right, and "8" makes it fall faster. At the same time, a gravity counter periodically tries to move the piece down by one row. Before every movement or rotation, a collision function checks whether the new position would overlap the walls, the floor, or blocks already on the board. When downward movement is no longer possible, the piece is locked into the board. The game then checks for completed rows, removes any full rows, shifts the remaining blocks downward, updates the cleared-line counter shown on the LEDs, and starts the next piece. If a new piece cannot be placed at the top because the board is full, the game enters the game-over state.

The design is made up of four modules. `top.v` integrates all the modules and drives the VGA color output based on the game state. `vga_sync.v` generates the 25 MHz pixel timing, hsync and vsync pulses, and pixel coordinate counters from the 100 MHz system clock. `keypad_scanner.v` scans the keypad to detect key presses, applies debouncing, outputs the corresponding key code and supports held keys. `tetris_game.v` stores the 10×20 playing board in register memory and runs the state machine that handles piece spawning, movement, rotation collision checks, line clearing, and the LED line counter. The shapes are stored as 16-bit patterns and rotated through index remapping. A small LFSR selects the next piece.
