# FPGA-Based Car Game 

This project is a car-dodging game written in Verilog for a Digilent Basys3 FPGA and displayed on a VGA monitor. The player controls a green car on the left side of the screen using the Basys3's onboard buttons, moving it up and down to avoid oncoming traffic. Three orange obstacle cars continuously drive from the right edge of the screen to the left at random vertical positions.

Each time an obstacle safely passes the left edge, the player earns a point and the obstacle loops back to the right side at a new random position. The game becomes progressively harder because the speed of the incoming cars increases every few seconds. If any obstacle collides with the green car, the entire screen turns solid red to signal game over and the player must press the reset button to start again. Collisions are detected using comparisons between the position of the player car and each obstacle.

The design is made up of six modules. `top.v` integrates all the modules and drives the VGA output. `clk_div.v` generates a 25 MHz pixel clock from the onboard 100 MHz oscillator, and `vga_sync.v` drives standard 640×480 at 60 Hz timing, generating hsync, vsync, video_on and pixel coordinates. `debounce.v` waits to confirm that a button input is valid and not noise. `lfsr16.v` implements a 16-bit linear feedback shift register that randomizes the placement of the oncoming cars. Finally, `game_logic.v` contains the main game logic: it updates the player's position, moves the obstacles, gradually increases the game speed, keeps track of the score, checks for collisions, and decides the color of each pixel. Game state updates are clocked by the VGA vsync signal, so movement is synchronized to the 60 Hz frame rate.
