# FPGA-Based VGA Paint Program 

This project is an "etch-a-sketch" style paint program implemented in Verilog on a Digilent Basys3 FPGA, displayed on a VGA monitor. The cursor is moved using two potentiometers: one controls horizontal position and the other controls vertical position, so turning both at once moves the cursor diagonally. The hardware consists of the Basys3 board, a VGA screen for the canvas, two potentiometers wired to the board's analog inputs, the onboard switches and the onboard center button.

When the system starts, it shows a blank black canvas. Switch 15 acts as the pen control: with the switch off, the cursor moves freely across the screen without changing any pixels, with the switch on the cursor paints as it moves. Switches 0 to 2 select one of eight drawing colors. The center push button clears the canvas at any time.

The design is made up of seven modules. `top.v` integrates all modules and drives the VGA output. `clk_div.v` generates a 25 MHz pixel clock from the onboard 100 MHz oscillator, and `vga_sync.v` produces standard 640×480 at 60 Hz timing, generating hsync, vsync, video_on and pixel coordinates. `debounce.v` confirms that an input is valid and not noise. `dual_pot_reader.v` instantiates the Xilinx `xadc_wiz_0` in Channel Sequencer mode to continuously sample the analog voltages on pins VAUX6 and VAUX14. `cursor_ctrl.v` applies the digital low-pass filter, scales the readings, and moves the cursor. Finally, `frame_buffer.v` implements a dual-port 160×120 video frame buffer, initialized to black, that supports writing pixel data and reading for display at the same time.
